Cette page a été publiée depuis GitHub vers l'hébergement OVH.

version 4

Vérifier le déploiement automatique :

  1. Sur GitHub, ouvrez index.html et cliquez sur le crayon.
  2. Remplacez version 1 par version 2.
  3. Enregistrez la modification (bouton Commit changes).
  4. Attendez une minute, puis rechargez cette page.

Si le numéro a changé, le webhook est opérationnel et toute la chaîne est validée. S'il n'a pas changé, consultez les informations du dernier déploiement dans l'espace client OVH, onglet Multisite.
